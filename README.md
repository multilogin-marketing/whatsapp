## 📱 What Is a Cloud Phone for WhatsApp?

A Multilogin cloud phone is a real ARM Android device hosted in a data centre. You see its screen in Multilogin and use it like a phone.

| | What it means for WhatsApp |
|---|---|
| **Native app** | You install WhatsApp or WhatsApp Business from the built-in store or as an APK. This is the mobile app, not WhatsApp Web. |
| **Primary device** | The cloud phone is the account's main phone. WhatsApp Web and Desktop can be linked to it. |
| **Persistent session** | App data and login history stay on the device between sessions. |
| **One cloud phone per account** | Each account has its own device, app data, location, and IP. Nothing is shared. |
| **Connection per device** | Choose Cellular or Wi-Fi and a built-in residential proxy, or add your own HTTP, HTTPS, ISP, or SOCKS5 proxy. |

## How WhatsApp Works on a Multilogin Cloud Phone

1. **One number = one account = one cloud phone.** Five accounts need five numbers and five cloud phones.
2. **The verification code goes to the number, not the cloud phone.** You read it elsewhere and type it into WhatsApp.
3. **Messages wait for you.** WhatsApp delivers them when you start the cloud phone. Mobile minutes count only while it runs.
4. **Linked devices need the phone every 14 days.** If WhatsApp Web is linked, start the cloud phone at least once every two weeks, or the linked session logs out.

## 📞 Phone Numbers for WhatsApp Cloud Phones: Where the Code Comes From

> **Multilogin cloud phones cannot receive SMS or calls.** WhatsApp sends a six-digit code by SMS or voice call, so every account needs a number that receives the code outside the cloud phone.

**Your options:**

- **Your own SIM or eSIM:** the easiest to verify again later, but one number per SIM.
- **A company landline:** works with WhatsApp Business through a voice call.
- **A rented number from an SMS service:** choose the country and read the code in the service's dashboard.
- **A one-time temporary number:** cheap for testing, risky for accounts you plan to keep.

Keep access to each number for as long as you run the account. WhatsApp asks for a new code when you reinstall the app or move the account to another device.

## How to Set Up WhatsApp on a Cloud Phone

1. **Create a cloud phone.** Choose from 30+ real Android device types across 12 brands, including Samsung, Xiaomi, Google, and OPPO, and pick the Android version.
2. **Set the connection.** Choose Cellular or Wi-Fi and a proxy in the same country as the number.
3. **Install the app.** WhatsApp or WhatsApp Business from the built-in store, or an APK.
4. **Verify the number.** Request the code, read it on your SIM, landline, or SMS service, and type it in.
5. **Name and tag the cloud phone** by number, brand, market, or client.
6. **Share it with your team** and set who can open it.
